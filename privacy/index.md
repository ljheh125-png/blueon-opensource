# Blueon 개인정보처리방침

시행일: 2026년 10월 31일

Blueon(이하 "본 앱")은 이용자의 개인정보를 소중히 다룹니다. 본 방침은 본 앱이
어떤 정보를 다루고, 무엇을 기기 밖으로 보내며, 무엇을 보내지 않는지 설명합니다.

## 1. 한눈에 보기

- 본 앱은 **회원가입이 없고 계정을 만들지 않습니다.**
- 이용자의 **동영상·음악 파일은 기기 안에서 처리되며, 개발자의 서버로 전송되지 않습니다.**
  이용자가 무선 파일 전송이나 공유 기능을 직접 사용할 때에만, 이용자가 고른 기기나 앱으로 전달됩니다.
- 재생 기록·재생목록은 **기기에만 저장**되고, 설정 일부는 이용자의 안드로이드 백업에 포함될 수 있습니다(9절).
- 앱이 비정상 종료되거나 오류가 나거나 재생이 오래 멈췄을 때 **진단 정보**가 전송됩니다.
- 본 앱은 **광고를 표시하지 않습니다**(5절).

## 2. 본 앱이 기기에서 다루는 정보

아래 정보는 **모두 기기 안에만 저장되며 외부로 전송되지 않습니다.**

| 무엇 | 왜 |
|---|---|
| 기기에 저장된 동영상·음악 파일의 목록과 정보(제목·길이·크기·경로) | 목록을 보여주고 재생하기 위해 |
| 재생 위치, 재생 기록, 즐겨찾기, 재생목록, 북마크 | 이어보기와 목록 기능을 위해 |
| 설정값(테마, 자막 크기·색, 재생 방식, 밝기 등) | 다음에 열었을 때 그대로 쓰기 위해 |
| 이용자가 지정한 대표 이미지 | 목록에 보여주기 위해 |
| 이용자가 열었던 네트워크 동영상 주소(최근 주소) | 다시 열기 쉽게 보여주기 위해 |
| 만들기에서 이용자가 직접 녹음한 소리 | 만들고 있는 영상에 넣기 위해 |

이 정보들은 앱을 삭제하면 함께 사라집니다.

## 3. 기기 밖으로 나가는 정보 (진단 정보)

본 앱은 안정성 개선을 위해 **Google Firebase Crashlytics**를 사용합니다.
앱이 비정상 종료된 경우, 앱이 멈추지 않고 넘어간 오류(예: 파일을 읽지 못함)가 발생한 경우,
재생 준비가 20초 넘게 멈춘 경우에 아래 정보가 전송됩니다.
Crashlytics는 오류 통계를 내기 위해 앱 실행(세션) 정보를 보낼 수도 있습니다.

- 오류가 발생한 위치와 원인(스택 트레이스)
- 기기 모델, 안드로이드 버전, 앱 버전, 기기 언어·지역
- 앱 설치 식별자(Crashlytics가 만드는 임의의 값으로, 이용자를 식별하지 않습니다)
- 오류 직전 앱이 어떤 작업을 하고 있었는지를 나타내는 짧은 표시
  (예: `[변환]`, `[자막 표시]`, 미디어 형식·코덱 이름, 파일 확장자)
- 재생이 멈춘 경우: 재생 위치와 전체 길이, 미디어 형식·코덱, 화면 크기, 주소 방식(예: `content`)

**보내지 않는 것을 분명히 밝힙니다.**

- 이용자의 동영상·음악·이미지 **파일 자체 또는 그 내용**
- **파일 이름, 폴더 경로, 곡 제목·아티스트 등 파일에서 읽은 정보**
- 이름·전화번호·이메일·주소 등 이용자를 식별할 수 있는 정보
- 위치 정보, 연락처, 통화 기록, 광고 식별자를 이용한 행동 추적
- 화면 이동이나 버튼 사용 같은 이용 행태 통계 (본 앱은 분석 도구를 사용하지 않습니다)

오류 문구에 파일 경로나 이름이 들어갈 수 있으면 그 문구를 지우고 보냅니다.

Crashlytics가 수집하는 정보는 Google의 처리 방침을 따릅니다:
<https://firebase.google.com/support/privacy>

## 4. 이용자가 직접 주소를 입력하거나 웹 검색을 하는 경우

본 앱에는 인터넷 주소를 입력해 재생하는 기능이 있습니다. 이 기능을 사용하면
**이용자가 입력한 주소의 서버로 직접 연결**됩니다. 본 앱의 개발자는 그 주소나
연결 내역을 수집하지 않으며, 해당 서버의 처리 방침은 그 서버 운영자에게 따릅니다.

가사나 자막을 찾을 때 이용자가 웹 검색을 누르면 곡이나 영상의 제목으로 채운 검색어가
앱 안의 웹 화면에서 **Google 검색**으로 전달됩니다. 이 검색은 Google의 처리 방침을 따릅니다.

## 5. 광고와 앱 안 구매

본 앱은 **광고를 표시하지 않으며**, 광고 SDK가 들어 있지 않고 광고 식별자(Advertising ID)를 사용하지 않습니다.
앞으로 광고를 넣게 되는 경우에는 **이 방침을 먼저 고쳐 게시한 뒤** 적용합니다.

현재 판매하는 앱 안 상품은 없습니다. 앞으로 상품을 판매하는 경우 결제는 **Google Play**가 처리하며,
본 앱은 결제 수단이나 결제 정보를 받지 않습니다. Google Play의 처리 방침: <https://policies.google.com/privacy>

## 6. 무선 파일 전송

이용자가 무선 파일 전송을 켜면, 휴대전화가 **같은 Wi-Fi에 있는 PC의 웹 브라우저**와
파일을 주고받을 수 있도록 잠시 연결을 엽니다.

- 파일은 **휴대전화와 그 PC 사이에서만** 오가며, 개발자나 다른 서버를 거치지 않습니다.
- 화면에 표시되는 6자리 코드를 입력한 브라우저만 접속할 수 있습니다.
- 이 연결은 **암호화되지 않습니다.** 신뢰할 수 있는 Wi-Fi에서만 사용하십시오.
- Wi-Fi가 바뀌거나 15분 동안 사용하지 않으면 연결이 저절로 종료됩니다.

## 7. 권한을 사용하는 이유

| 권한 | 왜 필요한가 |
|---|---|
| 사진·동영상·음악 접근 | 기기에 있는 미디어 파일을 찾아 목록에 보여주고 재생하기 위해 |
| 모든 파일 접근(선택) | 동영상 옆 자막 파일과 곡 옆 가사 파일을 알아서 찾아 붙이고, 안드로이드가 미디어로 분류하지 않는 형식을 목록에 보여주기 위해. 허용하지 않아도 재생은 되며, 허용하면 파일을 지울 때 시스템 확인창이 뜨지 않습니다 |
| 알림 | 재생 중인 곡의 조작 버튼, 편집 작업·무선 전송 진행과 완료 알림을 위해 |
| 마이크(선택) | 만들기에서 이용자가 녹음 단추를 누른 동안에만 소리를 녹음해 영상에 넣기 위해. 녹음한 소리는 기기 안에만 저장됩니다. 허용하지 않아도 녹음을 뺀 나머지 기능은 그대로 동작합니다 |
| 인터넷 | 주소로 재생하는 기능, 무선 파일 전송, 가사·자막 웹 검색, 이용자가 고른 편집 소재(효과음·음악)·글꼴·자동자막 모델 받기, 진단 정보 전송을 위해 |
| 설정 변경 | 이용자가 고른 음악을 벨소리로 지정하기 위해 |

권한은 해당 기능을 쓸 때에만 사용되며, 거부해도 나머지 기능은 그대로 동작합니다.

## 8. 아동의 개인정보

수집하지 않습니다.

## 9. 정보의 보관과 삭제

기기에 저장된 정보는 앱을 삭제하면 함께 삭제됩니다. 진단 정보는 Google의 보관
정책에 따라 일정 기간 후 삭제됩니다.

이용자가 기기에서 구글 백업을 켜 둔 경우 앱 설정 일부가 이용자의 구글 계정 백업에 포함될 수
있습니다. 재생 기록·재생목록·프로젝트·가사 파일은 백업에서 뺐습니다.
